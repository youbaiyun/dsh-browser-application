# Privacy policy — where the text lives

The policy itself is [`PRIVACY.md`](../../PRIVACY.md) at the repository root, because the
store form asks for a public URL for exactly that file. It used to be kept here as well
and published as a gist; two copies of a policy drift apart, so this file is a pointer.

The published URL must serve the current text. If it is the gist, replace the gist body
with `PRIVACY.md` and save — the policy promises a new revision per change, and a gist
save is a revision.
